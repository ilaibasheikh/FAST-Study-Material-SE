Login 
@startuml

actor User
participant "Web UI (React)" as UI
participant "Backend API" as API
participant "Auth Service\n(ASP.NET Identity)" as Auth
database "SQL Server DB" as DB
participant "Email Service\n(Resend API)" as Email

== Homepage ==
User -> UI: Visits IntelliMeet Pro website
UI -> API: GET / landing
API -> UI: Homepage shown to User

== Signup ==
User -> UI: Clicks "Sign Up"
UI -> API: POST /auth/signup (name, email, password)
API -> Auth: Create user (email, pass_hash)
Auth -> API: User created
API -> DB: INSERT workspace (workspace_id, owner_id)
DB -> API: Workspace created

== Email Verification ==
API -> Email: Send verification link
Email -> User: Verification email delivered

User -> API: GET /auth/verify?token=abc
API -> Auth: Validate and activate account
Auth -> API: Account verified

== Login ==
User -> UI: Enter email/password
UI -> API: POST /auth/login
API -> Auth: Validate credentials
Auth -> API: Return JWT + refresh token
API -> UI: Tokens returned

== Dashboard ==
UI -> API: GET /dashboard/init
API -> DB: SELECT workspace, users, history
DB -> API: Data returned
API -> UI: Dashboard payload
UI -> User: Display dashboard

@enduml

Meeting Trasncription
@startuml

participant Scheduler
participant "Backend API" as API
participant "Platform API\n(Zoom/Meet/Teams)" as Platform
participant "Whisper API" as Whisper
participant "Diarization Engine" as Diarization
database "SQL Server" as DB
participant "GPT Model" as GPT
participant "Pinecone Vector DB" as Pinecone
participant "PM Tools\n(Jira/Trello/Asana)" as PM

== Scheduled Meeting Start ==
Scheduler -> API: Scan for meetings due now
API -> DB: SELECT meetings WHERE start_time = NOW
DB -> API: Return meeting list

== Bot Joins Meeting ==
API -> Platform: Authenticate & join meeting
Platform -> API: Bot joined

== Transcription ==
loop For each audio chunk
    Platform -> API: Audio stream chunk
    API -> Whisper: Transcribe chunk
    Whisper -> API: Text + timestamps
    API -> Diarization: Identify speaker
    Diarization -> API: speaker_id
    API -> DB: INSERT transcript chunk
end

== Summary Generation ==
API -> GPT: Generate summary + action items
GPT -> API: Return summary + tasks

API -> DB: INSERT summary
API -> DB: INSERT action items

== Index to Semantic Search ==
API -> Pinecone: Store embeddings of transcript + summary
Pinecone -> API: Vector stored

== PM Tools Sync ==
loop For each action item
    API -> PM: Create task
    PM -> API: Task ID returned
    API -> DB: Update action item with external task ID
end

== End Meeting ==
API -> Platform: Leave meeting
Platform -> API: Success

@enduml

title State Diagram 1: Authentication & Account Lifecycle

[*] --> Start

Start --> SignupInitiated : User clicks Sign Up
SignupInitiated --> EmailSent : System sends verification email
EmailSent --> PendingVerification

PendingVerification --> Verified : User clicks verification link
PendingVerification --> SignupInitiated : Token expired / retry

Verified --> LoginAttempt : User enters email/password

LoginAttempt --> Authenticated : Valid credentials
LoginAttempt --> InvalidCredentials : Invalid credentials

InvalidCredentials --> LoginAttempt : User retries

Authenticated --> SessionActive
SessionActive --> LoggedOut : User logs out

SessionActive --> PasswordResetRequested : User clicks "Forgot Password"
PasswordResetRequested --> ResetTokenSent : Email with OTP
ResetTokenSent --> ResetCompleted : User sets new password
ResetCompleted --> LoginAttempt

LoggedOut --> LoginAttempt

@enduml
